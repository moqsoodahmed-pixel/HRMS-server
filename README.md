# DutyLaunch HRMS - Backend

Express.js + MongoDB REST API for the DutyLaunch HRMS system.

## Setup

```bash
npm install
cp .env.example .env
# Fill in your .env values
npm start
```

## Dev Mode
```bash
npm run dev
```

## Seed Database
```bash
npm run seed
```

## API runs on
`http://localhost:5000`
